# Idioma y nombres

- Responde siempre en español; el dueño (Sander) escribe en español.
- Todo lo nuevo va en español, igual que el código actual: textos de la interfaz, clases CSS (`.tarjeta`, `.redes`, `.caja`), variables CSS (`--sombra`, `--tinta`), funciones y variables JS (`agregar`, `render`, `tareas`) y comentarios.
- Los comentarios que marcan dónde editar contenido usan el prefijo `✏️`.
